# website-trunghai

Cổng thông tin điện tử chính thức **CÔNG TY CỔ PHẦN XÂY DỰNG VÀ ĐẦU TƯ TRUNG HẢI** (`trunghaico.vn`).

## 🛠 Công nghệ sử dụng
- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Database**: Cloudflare D1 (Serverless SQL Database)
- **Media CDN**: Cloudinary Media Storage
- **Triển khai**: Vercel (Hỗ trợ Edge / Serverless)

## 🚀 Hướng dẫn chạy thử nghiệm
1. Cài đặt thư viện:
```bash
npm install
```

2. Tạo file `.env.local` theo file `.env.example` và điền các API Keys tương ứng.

3. Chạy môi trường development:
```bash
npm run dev
```

4. Build môi trường production:
```bash
npm run build
```
